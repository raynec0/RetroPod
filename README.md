# RetroPod 0.1：经典 iPod 风格的音乐播放器

- 点按转盘：画圈滚动，每格有咔哒声和触感；上 MENU、下 ⏯、左 ⏮、右 ⏭，中间是选择键
- Cover Flow：每张专辑是有厚度的 CD 盒（书脊、透明塑料边、铰链和反光），左右滑动或转盘切换，按中心键翻到背面看曲目
- 正在播放：转盘调音量，按中心键切换为拖动进度
- 音乐来源：主菜单「导入音乐」，或用「文件」App 把歌放进「我的 iPhone › iPod」；读取歌名、艺人、专辑、曲号和封面
- 音乐 › 专辑 / 艺人 / 歌曲 / 播放列表（最常播放、最近播放）
- 设置：机身外观（经典白 / 黑色 / U2 特别版）、随机、重复、点按声
- 后台播放、锁屏和控制中心播放控件
- 屏幕 30 秒无操作自动变暗

## 编译

推送后 GitHub Actions 自动编译未签名的 `RetroPod.ipa`（在 Actions 运行页面底部的 Artifacts 下载），自签后安装。
